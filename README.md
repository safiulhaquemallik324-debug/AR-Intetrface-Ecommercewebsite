# 🛋️ ARShop – AR Furniture E-commerce Website

> Experience furniture before you buy with Augmented Reality.

ARShop is a modern and responsive furniture e-commerce website that combines **Augmented Reality (AR)** with online shopping. Users can browse furniture products, view detailed information, save favorites, manage their cart, and preview products in AR before making a purchase.
